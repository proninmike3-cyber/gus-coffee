# Гусь Кофейный — демонстрационный сайт

Одностраничный адаптивный сайт для кофейни **Гусь Кофейный**, Большая Комитетская ул., 15, Королёв (Юбилейный).

## Визуальная идентичность

Вторая версия базируется на визуальных атрибутах самой кофейни на Яндекс Картах: тонкий круглый знак с контуром гуся и кофейным зерном, чёрная графика, тёплый светлый фон, серый бетон/дерево в интерьере, неоновый жёлто-зелёный гусь. Вместо оригинального фирменного начертания на макете используется фактический графический логотип из карточки Яндекс Карт (`assets/official-logo.jpg`). Для случаев, когда он ещё не загружен, предусмотрена SVG-реконструкция мотива (`assets/logo-traced.svg`, *не оригинал*).

Фото интерьера скачиваются в `assets/coffee-counter.jpg` и `assets/coffee-interior.jpg` с карточки кофейни на Яндекс Картах через `.github/workflows/sync-brand-assets.yml`; доступны только локальные пути, не ссылки на сторонние хосты. Если они пока недоступны, отображается SVG-заглушка. Фото при разработке бралось по карточке заведения — перед коммерческим использованием стоит согласовать право использования с владельцем.

**Важно:** этот сайт — независимая демонстрационная версия, не официальный ресурс кофейни. Меню иллюстративное, цены намеренно не указаны. Цветовая система реконструирована на основе публичных материалов, это не официальный брендбук. Демо без админки.

### Публикация

Сайт полностью статический. Push в `main` запускает GitHub Pages. Все иконки SVG, нет внешних CDN для изображений.
