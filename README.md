# Гусь Кофейный — демонстрационный сайт

Адаптивный одностраничный сайт без панели управления и без сборки. Просто откройте `index.html` или опубликуйте папку как статический сайт (например, через GitHub Pages).

## Содержание
- `index.html` — страница, мета-теги, SEO и структурированные данные
- `styles.css` — собственный адаптивный дизайн
- `script.js` — вкладки меню, мобильная навигация, анимации
- `assets/*.svg` — **локальные** фирменные иллюстрации и логотип-концепт (внешних картинок нет)
- `favicon.svg` — локальная иконка

- Кофе с собой, бабл-ти, подарочный сертификат, Wi-Fi, гости с питомцами (Яндекс Карты)
- Капучино, раф, бабл-ти, какао, круассаны, эклеры, моти, шоколадный фондан и т.д. упомянуты в отзывах; реальный ассортимент и цены требуют сверки с владельцем.

## Перед запуском у клиента
1. Получить фирменный логотип в SVG и права на фото (нынешняя графика — **авторский концепт**, не официальный логотип).
2. Подтвердить режим работы. Справочники расходятся во времени открытия; сайт сознательно указывает только «до 21:00» с переходом в Яндекс.
3. Подтвердить полный актуальный прайс. На сайте показана подборка популярных типов напитков, **не** официальное полное меню.
4. Уточнить официальный ли Telegram @goosik_coffee, подарочные сертификаты и условия предзаказа десертов.
5. Сверить цитаты из отзывов и актуальность рейтинга перед продакшеном.
